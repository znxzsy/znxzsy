我在做模型训练前后那段不太显眼、却很费工程的工作：人类反馈数据、质量复核、模型评测，以及把这些流程整理成可以重复使用的工具。

最近把实际标注协作中遇到的数据丢失、版本冲突和归属不清整理成了 [AlignLedger](https://github.com/znxzsy/AlignLedger)。它能直接运行，也保留了从标注到训练数据导出的完整记录。
