我在做模型效果背后的数据工程：针对失败案例生产新数据，用人类复核守住质量，再用回归评测判断模型是否真的进步。

目前的工作集中在多模态学习、模型后训练、人类反馈和评测基础设施。比起单纯扩大数据量，我更关心每条数据为什么被生产、由谁确认、能否复现，以及它最终有没有带来可测量的提升。
